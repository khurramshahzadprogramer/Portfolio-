## 🔄 Development Process

The portfolio presents a four-step workflow:

1.  **Discover** --- Understand the goal, workflow, user, and desired
    outcome.
2.  **Architect** --- Choose the AI, tools, APIs, data flow, and product
    structure.
3.  **Build** --- Implement the system and create a clear responsive
    interface.
4.  **Refine** --- Test, improve reliability, and polish the experience.

## 💻 Run Locally

This portfolio is built as a standalone HTML project, so no package
installation is required.

### 1. Clone the repository

``` bash
git clone https://github.com/khurramshahzadprogramer/your-repository-name.git
cd your-repository-name
```

### 2. Open the project

Open `index.html` directly in your browser.

You can also use **VS Code + Live Server** for local development.
